Apple 공증 없는 개인 빌드이므로 브라우저로 .dmg를 내려받아 설치하면 macOS에서 "손상되었기 때문에 열 수 없습니다" 경고가 표시될 수 있습니다. 아래 터미널 명령을 실행하면 최신 버전 다운로드, /Applications/Typomm.app 교체, 격리 속성(com.apple.quarantine) 제거까지 한 번에 완료됩니다.

curl -fsSL https://imredcat.github.io/typomm/install.sh | bash

v0.2.20 주요 변경 사항

  • .typomm 압축 바이너리 포맷(v2) 전환: 기존 JSON 텍스트 방식에서 Deflate 압축이 포함된 경량 바이너리 포맷으로 전환해 파일 크기를 대폭 줄이고, 암·복호화를 Rust 백엔드로 일원화했습니다. (기존 v1 JSON 파일 하위 호환 유지)
  • 암호화 문서 앱 내 내용 검색 지원: 메모리 캐시 기반 복호화 검색을 도입해 폴더 탐색기, 최근 파일, 탭 검색에서 .typomm 암호화 파일의 본문도 빠르게 검색할 수 있습니다.

설치 안내

  • macOS (권장: 터미널 자동 설치): 위 curl -fsSL https://imredcat.github.io/typomm/install.sh | bash 명령어를 실행하면 손상 경고 없이 바로 설치/업그레이드됩니다.
  • macOS (DMG 직접 설치 시): 내려받은 .dmg를 열어 Typomm.app을 Applications 폴더로 복사한 뒤, 실행 시 손상 경고가 뜨면 터미널에서 xattr -cr /Applications/Typomm.app을 한 번 실행해 주세요.
  • Windows: .exe 또는 .msi 파일을 실행해 설치하세요. SmartScreen 안내가 뜨면 추가 정보 → 실행을 선택하면 됩니다.
