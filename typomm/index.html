v0.2.9 주요 변경 사항

  • 마크다운 코드블록 신택스 하이라이팅: ```php, ```js, ```sql 등 언어/확장자 지정 시 실시간 문법 강조와 우측 상단 언어 배지가 적용됩니다.
  • 비텍스트 파일 페이지 뷰 제한 & 검색 확장자 sql 추가: 일반 텍스트·마크다운 외 파일에서는 페이지 뷰가 꺼진 상태로 유지되며, 기본 내용 검색 확장자에 sql을 추가하고 환경설정 경고 안내를 표시합니다.
  • 실행·타이핑·검색 성능 대폭 개선: lowlight 및 보조 패널 지연 로딩으로 초기 번들을 약 43% 경량화하고, Rust BMH 멀티스레드 병렬 내용 검색·비동기 파일 I/O·메모이제이션으로 반응 속도를 높였습니다.

설치 안내

  • macOS: 내려받은 .dmg 파일을 열어 Typomm.app을 Applications 폴더로 드래그하세요. 공증되지 않은 개인 빌드이므로 최초 실행 시 Gatekeeper 경고가 표시되면 터미널에서 xattr -cr /Applications/Typomm.app을 실행하거나 앱을 Control + 클릭 → 열기로 실행해 주세요.
  • Windows: .exe 또는 .msi 파일을 실행해 설치하세요. SmartScreen 안내가 뜨면 추가 정보 → 실행을 선택하면 됩니다.
